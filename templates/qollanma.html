📖 Nakrutka API Qo'llanma

Salom! Bu qo'llanma Nakrutka bot API'sini qanday ishlatishni o'rgatadi.

📌 Muhim Bilgi
  • Barcha request GET orqali yuboriladi
  • API kalitingiz parameterda yuboriladi: ?api_key=YOUR_API_KEY
  • Base URL: http://localhost:5000/api
  • Rate Limit: 30 so'rov/minut har bir API key uchun
  • Javoblar JSON formatida qaytadi

🎯 Tez Boshlash:

Misol: Balansni Olish
GET /api/user/balance?api_key=YOUR_API_KEY

Javob:
{
  "success": true,
  "balance": 100.50,
  "currency": "$"
}

🔐 Autentifikatsiya

Barcha API requestlar uchun valid API kalit kerak bo'ladi.

API Kalit Olish:

  1. Telegramda botga qo'shiling
  2. "🤝 Hamkorlik" tugmasini bosing
  3. O'z API kalitingizni ko'ring
  4. "♻️ API kalit yangilash" orqali yangi kalit olish mumkin
⚠️ Xavfsizlik
  • API kalitingizni hech kim bilan bo'lishmang!
  • API kalit client-side qo'lda ulangtirish kerak (server-side yaxshi)
  • Agar kalit compromised bo'lsa, yangi kalit yarating

📦 Xizmat Buyurtma Qilish

GET /api/order/create

Yangi buyurtma yaratish va balansdan pul yechish

📤 Parametrlar:
Parametr Turi Tavsif
KERAK api_key string Sizning API kalit
KERAK service_id integer Xizmatning ID raqami
KERAK link string Instagram/TikTok/YouTube va h.k URL
KERAK quantity integer Ko'l (followers, likes va h.k)
📥 Javob (Muvaffaqiyatli):
200 OK 
{
  "success": true,
  "order_id": 98765,
  "service_name": "Instagram Followers",
  "quantity": 1000,
  "cost": 50.00,
  "currency": "$"
}
📥 Javob (Xatochun):
402 Payment Required 
{
  "error": "Insufficient balance. Required: 50.00, Available: 20.00"
}
🧪 Test Qilish:
GET /api/order/create?api_key=YOUR_API_KEY&service_id=123&link=https://instagram.com/username&quantity=1000

⚠️ Xato Kodlari va Javoblar

HTTP Status Kodlari:

Kod Tavsif Sabab
200 OK Request muvaffaqiyatli bajarildi
400 Bad Request Kerakli parametr yetishmaydi yoki noto'g'ri
401 Unauthorized API kalit noto'g'ri yoki mavjud emas
402 Payment Required Balans yetarli emas
429 Too Many Requests Rate limit ashtirildi (30/minut)
500 Server Error Server ichki xato ro'y berdi

Umumiy Xatolar:

API key yetishmaydi
{
  "error": "API key missing"
}
Noto'g'ri API key
{
  "error": "Invalid API key"
}
Rate limit ashtirildi
{
  "error": "Rate limit exceeded. Maximum 30 requests per minute."
}
Yetishmaydi parametrlar
{
  "error": "Missing required parameters: service_id, link, quantity"
}
Miqdor chegarasidan tashqari
{
  "error": "Quantity out of range. Min: 100, Max: 100000"
}
